Adaptación de Skills: Claude Code a Gemini Antigravity

Este documento justifica técnica y operativamente la migración de los recursos del curso (pensados originalmente para Claude Code) hacia nuestro entorno de trabajo con Gemini Antigravity.

Tabla Comparativa de Ecosistemas

Concepto (Curso / Claude Code) Adaptación (Gemini Antigravity / KIRO IDE) Justificación de la Adaptación
claude (Modo interactivo CLI) Interfaz del KIRO IDE / CLI de Antigravity Antigravity ya está integrado en el IDE, tiene contexto completo del workspace, y acceso directo a herramientas del SO, Playwright MCP y gestión de subagentes sin requerir instalaciones extra.
Directorio .claude/skills/ Directorio .agents/skills/ El sistema de "Customization" de Antigravity descubre automáticamente habilidades en la carpeta .agents/ en la raíz del proyecto. Al mover la carpeta logramos una integración nativa e instantánea de los recursos del curso (como create-scenarios, eventhub-domain, etc.).
/init o CLAUDE.md GEMINI.md (Manifiesto) En Antigravity, GEMINI.md sirve como el archivo de reglas raíz (Knowledge Skill) para inyectar instrucciones clave (como nuestras credenciales de prueba) en todo el proyecto.
Agent Skills & Knowledge Skills Antigravity Skills (SKILL.md) y Subagentes La estructura de SKILL.md de Claude Code es compatible con la de Antigravity. Ahora el agente puede cargar progresivamente estos conocimientos sin saturar su contexto de memoria (evitando el "Context Bloat").

Acciones Realizadas

  • Se migraron exitosamente las habilidades (Skills) desde eventhub/.claude/skills hacia la raíz del proyecto en .agents/skills.
  • Skills integradas: create-scenarios, eventhub-domain, generate-tests, playwright-best-practices, review-tests, test-strategy.
