1. Vulnerabilidad XSS Almacenado en Descripción

Crítica Seguridad

Área: Gastos e Ingresos > Nueva Transacción

Descripción: El campo de descripción de transacciones no escapa el código HTML/JS al renderizarse en la tabla, permitiendo inyección de scripts cruzados (XSS).

Pasos para reproducir:

  1. Navegar a "Gastos e Ingresos".
  2. Crear una nueva transacción.
  3. En el campo descripción, inyectar el payload: <img src="x" onerror="console.error('XSS executed!')">
  4. Hacer clic en Guardar.
  5. Observar la consola del navegador.

Logs (Red/Consola):

[ERROR] Failed to load resource: the server responded with a status of 404 (Not Found) @ http://localhost:3000/x:0 [ERROR] XSS executed! @ http://localhost:3000/:0

2. Excepción JS (TypeError) al Renderizar Objetivos Rotos

Alta Funcional

Área: Objetivos de Ahorro

Descripción: Al agregar un objetivo cuyo monto actual es mayor al objetivo, con fecha límite en el pasado, la app falla al intentar calcular el progreso o aplicar estilos, arrojando una excepción en consola y bloqueando la UI.

Pasos para reproducir:

  1. Navegar a "Objetivos".
  2. Hacer clic en "Nuevo Objetivo".
  3. Completar Monto Objetivo: 100000.
  4. Completar Monto Actual: 150000.
  5. Seleccionar Fecha límite en el pasado (Ej. 2023-01-01).
  6. Guardar y revisar consola.

Logs (Red/Consola):

TypeError: Cannot read properties of null (reading 'style') at renderGoals (http://localhost:3000/js/app.js:499:16) at HTMLFormElement.saveGoal (http://localhost:3000/js/app.js:580:5)

3. Desbordamiento de Interfaz por Descripciones Largas

Media UI / UX

Área: Gastos e Ingresos (Tabla)

Descripción: El campo "Descripción" no valida límite de caracteres (maxlength). Textos excesivamente largos rompen la estructura de la tabla y la responsividad de la página.

Pasos para reproducir:

  1. Navegar a "Gastos e Ingresos".
  2. Crear una transacción.
  3. Pegar un texto muy largo (ej. +500 caracteres sin espacios).
  4. Guardar y observar la tabla.

4. Problemas de Visualización con Valores Numéricos Extremos

Baja UI / Visual

Área: Dashboard y Tarjetas de Métricas

Descripción: Al ingresar transacciones con valores monetarios irracionales (ej. 10.000.000.000.000), el texto se desborda del contenedor en el Dashboard y en los Viewports móviles.

Pasos para reproducir:

  1. Navegar a "Gastos e Ingresos" e ingresar un gasto con Monto = 9999999999999999.
  2. Navegar al "Dashboard".
  3. Observar las tarjetas "Total Gastos" y "Balance".
  4. Cambiar el Viewport a Mobile (ej. iPhone X).
