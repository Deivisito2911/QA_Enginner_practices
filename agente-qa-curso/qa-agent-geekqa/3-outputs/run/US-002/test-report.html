🐛 BUG-US-002-01: Permite el registro de empleados menores de 18 años debido a validación incorrecta de edad

Categoría: Lógica Funcional / Regla de Negocio
Severidad: Alta
Prioridad: Alta

Pasos para Reproducir:

1. Navegar a https://testing1.geekqa.net/.
2. Completar todos los campos con valores válidos.
3. En el campo "Edad", ingresar un valor menor a 18 (ejemplo: 16).
4. Presionar el botón "Registrar Empleado".

Resultado Esperado: El sistema debe rechazar el registro, mostrar el mensaje de error "La edad debe estar entre 18 y 65 años" y no agregar el empleado a la tabla.

Resultado Actual: El empleado de 16 años es registrado exitosamente en la tabla sin mostrar error alguno, debido a que la condición en código verifica `age < 5` en vez de `age < 18`.

Recomendaciones Generales para el Equipo de Desarrollo

  1. Corrección Urgente en Validación de Salario: Sustituir el operador de asignación salary = 0 por una condición lógica if (parseFloat(salary) <= 0 || isNaN(salary)). Actualmente se corrompen los datos de nómina en la tabla.
  2. Alineación de Reglas de Edad con Negocio: Corregir la condición age < 5 || age > 60 a age < 18 || age > 65 para evitar registrar menores de edad y no discriminar a adultos mayores en edad de trabajar.
  3. Control de Validación de Género: Asegurar que la falta de selección de género active la bandera de error hasError = true; para impedir el registro de datos nulos.
  4. Consistencia en Mensajes de UI: Corregir el texto de éxito a "¡Empleado registrado con éxito!" y sincronizar las longitudes de Dirección y Teléfono con los mensajes mostrados al usuario.
  5. Accesibilidad Web: Envolver las opciones de género en <fieldset> y <legend> y vincular el checkbox de contrato con su etiqueta.
